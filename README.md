# Superstore Sales Dashboard (Power BI)

An interactive Power BI dashboard that analyzes Superstore sales data to track sales, profit, quantity and orders across categories, regions, states, customer segments and shipping modes.

## Visuals Included

- Sales by Category
- Profit by Category
- Sales by State
- Sales by Segment (Consumer, Corporate, Home Office)
- Sales by Region (West, East, Central, South)
- Sales by Ship Mode
- Slicers for Category, Region and Segment (click a value and the whole dashboard updates)

## Key Insights

- **Technology** gives the highest profit among all categories.
- **Furniture** has high sales but the lowest profit.
- **West** is the top region with about 31.6% of total sales.
- **Consumer** is the largest customer segment, with about 50% of sales.
- **Standard Class** is the most used shipping mode.
- **California** and **New York** lead in sales by state.

## Data Cleaning and Transformation

- Removed duplicates and blank rows
- Fixed data types (date, number, text)
- Handled null values
- Cleaned and prepared data using Excel and Power Query Editor

## Tools Used

- Power BI Desktop
- Power Query Editor
- DAX (measures and KPI cards)
- Microsoft Excel

## How to Open This Project

1. Download `Superstore_Sales_Dashboard.pbix` from this repository.
2. Open it in **Power BI Desktop** (free to download from Microsoft).
3. Click the slicers on the left to filter by Category, Region and Segment.

> GitHub cannot run Power BI files in the browser, so please use the demo GIF/video above if you do not have Power BI installed.
